0engine escalated

Scripted share is the part of handoffs a script routed straight to the next bot, scripted / (scripted + grok wakes), rather than one bot waking another.

how each count is made

scripted = jobs for claude, codex or cursor that `orch wait` claimed and the bot finished with an orch:v1 handoff comment (jobs.state = 'done' with a handoff_comment_id). Each one is a handoff routed from an orch:v1 comment to a bot by script, with no bot messaging another bot. scripted_in_flight = such jobs claimed and still running. bot_to_bot = jobs routed to grok: each one wakes Grok Bot to read the ticket and hand off by hand (stops, clarify, refusals, ship failures). scripted_share = scripted / (scripted + bot_to_bot). The database does not record bot messages sent outside the factory, so grok wakes are the measurable stand-in for bot-to-bot handoffs. engine_handled = granted plus landed rulings in the engine_decisions log, and engine_escalated = escalated rulings in that log.
