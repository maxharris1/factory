Scripted share is the part of handoffs a script routed straight to the next bot, scripted / (scripted + grok wakes), rather than one bot waking another.

how each count is made

scripted = jobs for claude, codex or cursor that `orch wait` claimed and the bot finished with an orch:v1 handoff comment. scripted_in_flight = such jobs claimed and still running. bot_to_bot = jobs routed to grok: each one wakes Grok Bot to read the ticket and hand off by hand (stops, clarify, refusals, ship failures). The database does not record bot messages sent outside the factory, so grok wakes are the measurable stand-in for bot-to-bot handoffs.
