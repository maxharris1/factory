- **Decision:** A `verdict=APPROVE` with `ac=unmet` fails to parse, so it never ships. A verdict the dispatcher refuses changes no state or round, wakes Grok Bot with its outcome, and queues the refused done review once more as a new attempt-1 job, marked by its `review-refused:` dedupe key so a T6 retry neither spends nor resets the allowance, and holds it while a fix for the same head is open. An APPROVE with no `ac` still parses and ships: requiring `ac=met` on every APPROVE failed 429 existing tests and is left for a follow-up.
