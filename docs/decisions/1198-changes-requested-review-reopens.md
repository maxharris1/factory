- **Decision:** On a `ship: handoff` ticket in `handed-off`, a GitHub PR review in state `CHANGES_REQUESTED`, submitted after the shipped APPROVE by an approver login or a `factory.md` `human_reviewers` login, acts as an approver's `state=building` go. Under the effective cap it reopens the ticket exactly as #1197 does, keyed on `review:<review id>`, and the fix brief asks for the changes the review requests, its inline comments included. At or over the cap it queues nothing: one transaction records `changes-requested-after-cap` in `review_events` and raises that attention flag once. The poll reads PR reviews only on `ship: handoff` repos.
- **When:** 2026-11-20, by Factory decided (technical), from Max's words on #1191 ("my go or a changes-requested review reopens a handed-off ticket under cap")
- **Source:** https://github.com/maxharris1/factory/issues/1198

A review is turned into a comment with id `review:<review id>` and goes through #1197's `_lift_cap`, so the reopen, its `review_events` replay row and the Linear reopen are the same code as the go's. The caller checks trust before `_lift_cap`, so `github_app.enabled` and `go-not-from-approver` do not apply to a review: an untrusted review is ignored without a wake. A `COMMENTED`, `APPROVED`, `DISMISSED` or `PENDING` review changes nothing, and so does a `CHANGES_REQUESTED` review submitted at or before the approval, or on a ticket that is not `handed-off`. A `capped` ticket still needs Max's go. Only the first qualifying review in submission order reopens, since the ticket then leaves `handed-off`. A replayed review finds its `review_events` row and queues nothing, raises no second flag and leaves the round alone.

"After the approval" compares the review's `submitted_at` with the time of the APPROVE comment whose ship intent completed last, the same APPROVE #1197 takes the completed round from. A ready-for-review handoff never writes `approved_at`, so that column cannot be the reference. A handed-off ticket with no completed ship intent, or whose APPROVE comment is not in the read, ignores reviews.
