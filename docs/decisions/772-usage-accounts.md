- **Decision:** Usage is tracked per subscription: `machines.yml` names each one under `accounts:`, and readings, lane pauses and Efficiency rows key on the account. The `usage_readings` primary key stays `(harness, bot, device, window)` and `account` is a column every reader keys on, which departs from the ticket's design point 3. One bot login on one device is one subscription, so `(harness, bot, device)` already names the account; a rebuilt key adds nothing, needs a table rebuild, and would break the upsert of older code still running during self-heal restarts (#748). Several bot users for one harness on one device is deferred, the `orch usage record` allowlist is the accounts with `harness: external`, and `plan` comes from `machines.yml` only.
